# Git, GitHub & Linux

Most robotics software runs on Linux, and almost every team keeps its code on GitHub. In this workshop you'll learn your way around the Ubuntu command line, track your work with Git, and collaborate with other people through GitHub, the same way the club's project teams do.

| | |
|---|---|
| **Level** | Beginner |
| **Duration** | TODO, e.g. 3 hours |
| **Prerequisites** | None |

## What you'll learn

- Get around the Ubuntu command line: files, folders, editing and installing software
- Track changes to a project with Git: commits, history and branches
- Put your code on GitHub and keep it in sync
- Work with other people using pull requests, and fix merge conflicts
- Contribute to a project you don't own using a fork

## What to bring

- [ ] Laptop (Windows, macOS or Ubuntu)
- [ ] A free [GitHub account](https://github.com/signup)
- [ ] Ubuntu and Git set up **before** the workshop, by following [Install & set up](02-setup.md). On Windows this needs a restart, so don't leave it until the day.
