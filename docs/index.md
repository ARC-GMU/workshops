# ARC Workshops

![Autonomous Robotics Club logo](assets/logooo_circlebg.png){ width="180" }

Hands-on workshops from the Autonomous Robotics Club at GMU. You don't need any experience: pick a workshop below or follow a learning path.

## Workshops

<div class="grid cards" markdown>

-   :material-git:{ .lg .middle } **Git, GitHub & Linux**

    ---

    The Ubuntu command line, plus tracking and sharing code with Git and GitHub. Most other workshops use them, so start here.

    [:octicons-arrow-right-24: Start workshop](software/git-github-linux/index.md)

-   :material-flash:{ .lg .middle } **Electronics Basics & Multimeter**

    ---

    Voltage, current and resistance, and how to measure them safely.

    [:octicons-arrow-right-24: Start workshop](hardware/electronics-basics-multimeter/index.md)

-   :simple-arduino:{ .lg .middle } **Arduino for Beginners**

    ---

    Program a microcontroller to blink LEDs, read buttons and drive hardware.

    [:octicons-arrow-right-24: Start workshop](hardware/arduino-beginners/index.md)

-   :simple-raspberrypi:{ .lg .middle } **Raspberry Pi for Beginners**

    ---

    Set up a Linux computer the size of a credit card and control hardware with Python.

    [:octicons-arrow-right-24: Start workshop](hardware/raspberry-pi-beginners/index.md)

-   :material-cube-outline:{ .lg .middle } **CAD for Beginners**

    ---

    Design your first 3D part, ready to print or machine.

    [:octicons-arrow-right-24: Start workshop](mechanical/cad-beginners/index.md)

</div>
