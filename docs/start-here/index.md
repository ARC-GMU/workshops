# Start Here

New to the club's workshops? Read this page first.

## How workshops work

- Each workshop is a set of short lessons. Do them in order.
- Each workshop's first page lists its prerequisites, what to bring, and how long it takes.
- Starter code is in the [workshops repo](https://github.com/ARC-GMU/workshops) under `code/`. Each lesson links to its files.
- Stuck? Ask in the [Discord](https://discord.gg/zn93yRNZGb).
